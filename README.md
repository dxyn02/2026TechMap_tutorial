## 📖 소개
이 프로젝트는 visionOS의 ARKit을 활용한 공간 컴퓨팅 앱과, 해당 앱의 핵심 기능인 Room Tracking을 구현하는 방법을 배우는 **DocC 기반 튜토리얼**을 포함하고 있습니다. 

## ✨ 주요 기능
- **[기능 1]**: RealityKit을 활용한 3D 객체 렌더링
- **[기능 2]**: Room Tracking을 활용한 방별 환경 구성하기
- **DocC 튜토리얼**: 프로젝트에 포함된 단계별 튜토리얼을 통해 핵심 코드를 직접 따라 하며 학습할 수 있습니다.

## 🛠️ 요구 사항
- **Xcode 26.6** 이상
- **visionOS 26.2** 이상
- **Swift 6.3** 이상
